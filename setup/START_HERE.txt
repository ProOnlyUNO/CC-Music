CC Music Tools — in-game setup map
==================================

Friendly guide: which files go on which computer.
Made so anyone can set this up without guessing.

Monitors (recommended)
----------------------
  Main jukebox UI ........ 9x3 Advanced Monitor, scale 0.5
  Side visualizers ....... 4x4 Advanced Monitor each, scale 0.5

Folders in this setup pack
--------------------------
  main-computer/     → copy onto the MAIN music computer
  side-visualizer/   → copy onto EACH side visualizer computer
  pocket-remote/     → copy onto the Pocket Advanced Computer

Quick path
----------
  1. Open each folder’s README.txt and copy those .lua files onto that machine.
  2. Put an Ender Modem (wireless) on main + pocket (+ sides if you use viz).
  3. Optional auto-start:  edit startup   then e.g.  shell.run("jukebox")
  4. On Windows, use CC Music Tools: Convert → Fetch lyrics → drop files with Importer.

Startup tip
-----------
  F5 only rescans music files. After you replace a .lua script, restart the
  program (or reboot the computer) so the new code actually loads.

You’re set — enjoy the music.
